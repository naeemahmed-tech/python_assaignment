# Python Assignment – Module 2

This repository contains the two Python programs for Django Batch-14, Module-2 Assignment.

## Assignment Tasks

### 1. Student Grade Calculator
- Takes a student's name as input.
- Takes marks for three subjects.
- Calculates total marks and average marks.
- Determines the grade based on the average:
  - 80–100: A+
  - 70–79: A
  - 60–69: B
  - 50–59: C
  - Below 50: F
- Displays the result using an f-string.

### 2. Simple Shopping Cart
- Takes the customer's name as input.
- Takes the names and prices of three products.
- Calculates subtotal, discount, and final total.
- Applies discounts based on the subtotal:
  - 5000 or above: 20%
  - 3000–4999: 10%
  - 1000–2999: 5%
  - Below 1000: No discount
- Displays the shopping summary using f-strings.

## Project Files

- `student_grade_calculator.py` — Student marks and grade calculation.
- `shopping_cart.py` — Shopping subtotal, discount, and final total calculation.

## Requirements

- Python 3

## How to Run

Open a terminal in this folder and run either program:

```bash
python student_grade_calculator.py
```

```bash
python shopping_cart.py
```
